# Kay's Photo Magic ✨
Native Android starter app with purple and pink UI, paperclip photo picker, prompt input, basic offline resizing, save and share. The AI generation/editing provider is NOT connected yet; AI generation, photo combining, advanced restoration, and Google Play release signing are future work.

## Download APK
Open GitHub Actions > Build Android APK > latest successful run > Artifacts > Kays-Photo-Magic-debug-APK. Unzip and install app-debug.apk on a compatible Android device.

The GitHub Actions build runs on pushes to main. Check that the run succeeds before attempting installation. Do not store API keys in the repository.
